MobilePay (Vipps) Payment Provider

Seamless payments for the Danish market

Integrate MobilePay Online (Vipps ePayment API v3) directly into your Odoo eCommerce and Invoicing flows. Enable your customers in Denmark to pay effortlessly using their mobile phones with support for DKK.

Key Features

Secure & Compliant

Fernet-encrypted credential storage, HMAC-verified webhooks, and full support for Authorize & Capture flows.

Advanced Capture Flows

Flexible capture options: Manual, Capture on Delivery (Stock integration), or Automatic after a configurable delay.

Real-time Status

Immediate payment status updates via webhooks and active polling fallback for maximum reliability.

Full Refund Support

Process full or partial refunds directly from the Odoo backend with real-time API synchronization.

Enterprise Ready

Fully compatible with Odoo Enterprise and Community editions. Features built-in diagnostic tools for API connectivity testing and webhook management.

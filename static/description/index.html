MobilePay (Vipps) Payment Provider

Odoo 18 development integration for the Danish market

Not production-ready. Lifecycle and checkout gaps are repaired and locally tested with synthetic payments. Live merchant/app/webhook acceptance is blocked; the legacy settlement API adapter still requires migration. See README.md and MIGRATION-18.0.md in the addon source.

Integrates with MobilePay Online (Vipps ePayment API) for Odoo eCommerce and invoicing. The seeded payment method targets Denmark and DKK.

Key Features

Credentials and Webhooks

Fernet credential storage and HMAC webhook verification code are implemented. Live webhook acceptance remains required.

Advanced Capture Flows

Full/partial capture, delayed cron and real delivery/backorder workflows are locally tested. Delivery mode captures the full remainder on the first completed delivery.

Real-time Status

Webhook and polling handlers exist. Synthetic authorization and capture status processing is tested; live delivery is not verified.

Refund and Void Integration

Refund children, backend refund wizard, outbound payments and remaining-authorization cancellation are tested with mocked API responses.

Compatibility

Fresh installation and update on Odoo 18 Community: 91 registered tests, plus local Chromium checkout acceptance. Enterprise and live payment acceptance have not been tested.
